# Kalaha CLI game engine

Source: https://github.com/davwul/kalaha_game/blob/main/Kalaha_FINAL.ipynb

## Installation

1. Extract the project from the provided `.zip` file.
2. Ensure [Python 3](https://www.python.org/downloads/) is installed on your system.
3. No additional dependencies are required—the game uses only Python's standard library.

## How to Run

From the extracted project folder, open a terminal and run:

```bash
python play.py
```

Or, if you need to use Python 3 explicitly:

```bash
python3 play.py
```

You will be prompted to enter your name, then take turns playing against the AI. Choose a bowl (1–6) when it's your turn.
